외부 글(예: Nature 칼럼)의 전문 번역은 `참고/`에 강의 준비용으로만 둔다. 원고 편(같은 레벨의 번호 붙은 파일)으로 옮기거나 수강생 배포 자료로 쓰지 않는다.

**Why:** 2026-10-26, 저자가 `1-week/참고/프롬프트실험.md`(Nature 칼럼 번역)를 `05-프롬프트-심화`로 올리려다 저작권(2차적 저작물 배포) 문제로 그대로 두기로 했다.

**How to apply:** 번역본을 원고로 올리자는 제안은 다시 하지 않는다. 원고에서 쓰려면 요약·해석·출처 링크 방식으로 저자 1인칭 편을 새로 쓰는 쪽을 제안한다.
