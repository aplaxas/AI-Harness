# 7. 여러 단계의 업무 — 문의·매출 보고

## 이 시간의 목표

여러 단계가 이어지는 업무를 같은 설계서로 나누고, 단계 사이에 멈출 자리를 정해 두 도구에 맡길 수 있다. 두 도구에서 진행 확인과 승인이 어떻게 다른지 비교할 수 있다.

## 핵심 한 줄

**단계가 길어질수록 결과는 진행 확인과 승인 자리에서 갈린다.**

## 2주차 과제 공유 (15분)

2주차 과제로 내 업무를 한 도구에 맡겨 본 결과를 짧게 나눈다. 검수표에서 걸린 항목 하나와 고친 점 하나씩 말한다.

## 오늘의 업무

동네빵집 사장의 월말 업무다. 아래는 설명을 위해 만든 가상 업무이고, 자료는 [실습자료](실습자료/README.md)의 `사례2-문의매출` 폴더에 있다.

> 10월에 들어온 고객 문의 10건과 10월 매출 기록을 정리해서, 다음 달 운영에 쓸 한 장짜리 보고와 손님용 안내문 초안을 만든다.

회의록과 다른 점은 **단계가 이어진다**는 것이다. 앞 단계가 틀리면 뒤 단계가 모두 틀린다.

| 단계 | 하는 일 | 결과 파일 |
| --- | --- | --- |
| 1. 문의 분류 | 문의를 유형별로 나누고 정책에 비춰 본다 | 문의분류.xlsx |
| 2. 답장 초안 | 문의마다 정책 안에서 답장 초안을 쓴다. 약속은 비워 둔다 | 답장초안.docx |
| 3. 매출 정리 | 품목별·주별 합계를 내고 이상한 행을 표시한다 | 매출요약.xlsx |
| 4. 운영 보고 | 1~3을 묶어 사장용 한 장 보고를 만든다 | 운영보고.docx |
| 5. 안내문 | 자주 온 문의를 바탕으로 손님용 안내문 초안 | 안내문초안.docx |

## 설계서: 단계 사이에 멈출 자리

5의 설계서를 그대로 쓴다. 바뀌는 것은 5번 "진행 확인"이다. 단계가 길면 **어디서 멈춰 내가 볼지**를 미리 정한다.

| 항목 | 이 업무 |
| --- | --- |
| 1. 결과물과 완료 기준 | 위 표의 파일 다섯 개. 모든 답장에 정책 근거가 있다. 매출 합계를 원본과 맞출 수 있게 계산 방식을 적는다 |
| 2. 작업 폴더 | `원본`(문의, 매출), `참고`(정책, 안내문 예시), `결과` |
| 3. 범위와 승인 | 읽기: 작업 폴더. 쓰기: 결과 폴더만. 원본 수정·삭제 금지. 메일·메시지 발송 없음 |
| 4. 요청서 | 아래 상자 |
| 5. 진행 확인 | **멈춤 1**: 1단계 분류표가 나오면 멈춘다. **멈춤 2**: 3단계 매출 합계가 나오면 멈춘다. 둘 다 내가 확인한 뒤 다음으로 |
| 6. 검수 | 아래 검수표 |
| 7. 남길 것 | 8에서 |

여기서부터는 내 해석이다. 멈춤 자리는 "틀렸을 때 뒤가 다 틀리는 곳"에 둔다. 이 업무에서는 분류와 합계다. 분류가 틀리면 답장과 안내문이 틀리고, 합계가 틀리면 보고가 틀린다. 답장 초안 하나하나에는 멈추지 않는다. 마지막에 한꺼번에 봐도 뒤에 영향을 주지 않기 때문이다.

```text
[목적] 동네빵집 사장이 11월 운영을 정할 수 있게, 10월 문의와 매출을 한 장으로 정리한다.
       자주 온 문의는 손님용 안내문으로 미리 알린다.
[자료] 원본/고객문의_10월.csv, 원본/매출_10월.csv.
       참고/가게정책.md(답의 근거), 참고/안내문예시.md(말투).
[조건]
- 답장은 가게정책.md 안에서만 쓴다. 정책에 없는 보상·할인·환불은 약속하지 않고
  [사장 결정]으로 비워 둔다.
- 건강·알레르기 문의에는 "괜찮다"고 답하지 않는다.
- 날짜와 요일은 달력과 맞춰 본다. 고객이 말한 요일이 틀리면 답장에서 되묻는다.
- 매출 원본은 고치지 않는다. 중복·빈칸·마이너스처럼 이상한 행은 지우지 말고
  목록으로 보고하고, 어떻게 처리했는지 적는다.
[결과 형식] 결과 폴더에 문의분류.xlsx, 답장초안.docx, 매출요약.xlsx,
           운영보고.docx(A4 한 장), 안내문초안.docx.
[하지 말 것] 원본·참고 폴더의 파일을 고치거나 지우지 않는다. 메일이나 메시지를 보내지 않는다.
[진행] 바로 시작하지 말고 계획을 먼저 보여 줘.
       1단계 분류표를 만든 뒤 멈추고 나에게 보여 줘.
       3단계 매출 합계를 만든 뒤 멈추고, 이상한 행 목록과 처리 방식을 보여 줘.
[완료 보고] 만든 파일 목록, [사장 결정]으로 남긴 곳, 내가 확인해야 할 점.
```

## 두 도구에서 달라지는 자리

6에서 본 폴더·권한·요청서 자리는 같다. 이번에는 단계가 길어서 **목표, 진행 확인, 승인**의 차이가 더 크게 보인다.

| 항목 | Codex·ChatGPT Work | Claude Cowork | 그대로인 것 |
| --- | --- | --- | --- |
| 목표와 완료 기준 | `/plan`으로 시작하면 질문을 주고받으며 성공 기준이 있는 목표를 만든다. 목표는 진행 줄에서 일시정지·수정할 수 있다 | 계획을 세워 보여 주고, 내가 확인한 뒤 진행한다 | 다섯 파일과 완료 기준 |
| 멈춤 자리 | 요청서의 "멈추고 보여 줘"를 따른다. 진행 중에 메시지로 끼어들 수 있다 | 요청서의 "멈추고 보여 줘"를 따른다. 진행 중에 멈추거나 방향을 바꿀 수 있다 | 멈춤 1, 멈춤 2의 위치 |
| 진행 보기 | 옆 패널에 계획·자료·만든 파일. **Activity**에서 실행 중·입력 대기 작업을 모아 본다 | 단계별 진행 표시. 다른 기기에서 같은 작업을 열어 확인·답할 수 있다 | 내가 무엇을 확인할지 |
| 승인 | 작업 폴더 밖 편집, 네트워크가 필요한 일, 되돌릴 수 없는 도구 사용에 승인을 묻는다 | Manual에서는 행동 전에 묻는다. 파일 영구 삭제는 항상 묻는다 | 발송·삭제 금지는 요청서에 적는다 |
| 오래 걸릴 때 | 로컬 작업은 컴퓨터가 켜져 있어야 한다(Mac은 실행 중 잠자기 방지 설정) | 로컬 파일 작업은 데스크톱 앱이 열려 있어야 한다 | 멈춤 자리에서 내가 자리에 있어야 한다 |

## 검수표

강사노트에 기준값이 있다. 수강생은 아래 항목을 직접 원본과 대조해서 채운다.

| 확인할 것 | Codex·ChatGPT Work | Claude Cowork |
| --- | --- | --- |
| **멈춤 1**에서 실제로 멈췄나 | | |
| 문의 10건이 빠짐없이 분류됐나 | | |
| 고객이 말한 날짜·요일이 달력과 맞는지 확인했나 | | |
| 정책에 없는 환불·쿠폰·보상을 약속한 답장이 있나 | | |
| 알레르기 문의에 "괜찮다"고 답했나 | | |
| 예약 기한(3일 전, 2일 전 취소) 계산이 맞나 | | |
| **멈춤 2**에서 실제로 멈췄나 | | |
| 매출의 중복·빈칸·마이너스 행을 찾아 보고했나 | | |
| 처리 방식을 밝혔나 (지웠나, 채웠나, 남겼나) | | |
| 합계를 계산기나 Excel로 다시 냈을 때 같은가 | | |
| 원본·참고 폴더가 그대로인가 | | |
| 운영 보고가 A4 한 장인가, 숫자가 매출요약과 같은가 | | |

여기서부터는 내 해석이다. 이 표에서 가장 중요한 줄은 맨 위와 가운데의 "실제로 멈췄나"다. 멈추지 않고 끝까지 간 결과가 우연히 맞더라도, 다음 업무에서는 틀린 분류 위에 보고서가 쌓일 수 있다.

## 민감한 문의 하나

자료 중 한 문의에는 "아이가 견과류 알레르기가 있다"는 내용이 있다. 1주차 [3-1. 보안](03-보안-1.md)에서 본 대로 건강 정보는 민감한 정보다. 이 실습 자료는 이름이 없는 가상 자료라 그대로 쓴다. 실제 가게 자료라면 어떻게 할지 짝과 이야기한다.

- 이 문의를 빼고 맡길까, 문장을 바꿔서 맡길까?
- 이런 문의의 답장은 처음부터 내가 쓰는 편이 나을까?

> ✍️ **[채우기]** 여러 단계짜리 업무를 맡겼다가 중간에 멈춰서 바로잡은 실제 경험, 또는 멈추지 않아서 뒤 단계까지 다시 한 경험.

## 실습 (40분)

1. `사례2-문의매출` 폴더를 두 번 복사한다.
2. 위 요청서를 두 도구에 그대로 붙여 넣는다.
3. 멈춤 1, 멈춤 2에서 두 도구의 결과를 나란히 놓고 확인한 뒤 진행시킨다.
4. 검수표를 채우고, 두 도구에서 갈린 항목에 표시한다.

## 정리

- 여러 단계의 업무는 "틀리면 뒤가 다 틀리는 곳"에 멈춤 자리를 둔다.
- 멈춤 자리, 금지 사항, 완료 보고는 요청서에 적는다. 도구가 달라도 같은 문장이 통한다.
- 진행을 보는 화면과 끼어드는 방법은 도구마다 다르다. 무엇을 확인할지는 같다.
