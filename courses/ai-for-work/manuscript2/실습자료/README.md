# 실습자료

2·3주차 실습에 쓰는 **가상 자료**다. 회사, 가게, 사람, 숫자는 모두 지어낸 것이다. 사람 이름은 처음부터 "참석자 A"처럼 역할로 바꿔 두었다.

수강생은 이 폴더를 **통째로 복사해서** 자기 컴퓨터의 작업 위치에 둔다. 원래 폴더는 건드리지 않는다. 같은 업무를 두 도구에 맡기므로, 도구마다 따로 복사본을 하나씩 만든다.

```text
내 작업 위치/
├── 사례1-회의록_Codex/      ← 복사본 1
└── 사례1-회의록_Cowork/     ← 복사본 2
```

## 사례 1. 회의 메모 → 회의록 (2주차, [6. 회의록 비교](../06-회의록비교.md))

| 폴더 | 파일 | 내용 |
| --- | --- | --- |
| 원본 | 메모_1014.txt, 메모_1021.txt, 메모_1028.txt | 마케팅팀 주간회의 메모 3주치 |
| 참고 | 회의록양식.md | 회사 회의록 양식 |
| 결과 | (비어 있음) | 도구가 만든 파일이 들어갈 곳 |

## 사례 2. 고객 문의·매출 → 주간 운영 보고 (3주차, [7. 여러 단계 비교](../07-다단계비교.md))

| 폴더 | 파일 | 내용 |
| --- | --- | --- |
| 원본 | 고객문의_10월.csv | 휴스턴 롱포인트의 한인 동네빵집에 10월에 들어온 문의 10건 |
| 원본 | 매출_10월.csv | 동네빵집 10월 판매 기록. 금액은 달러다. Excel로 열 수 있다 |
| 참고 | 가게정책.md | 예약·환불·배달·알레르기 정책 |
| 참고 | 안내문예시.md | 지난달 안내문. 말투 참고용 |
| 결과 | (비어 있음) | 도구가 만든 파일이 들어갈 곳 |

자료에는 확인할 거리가 일부러 섞여 있다. 무엇인지는 실습 중에 찾는다.
