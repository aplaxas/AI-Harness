# 4. 회사별 최신 모델

> [목차](index.md) · 이전: [3-2. 일을 맡기는 도구의 보안 — 숨은 지시](03-보안-2.md) · 다음: [5. 업무 위임 가이드](05-위임가이드.md)

## 이 시간의 목표

회사별 최신 모델이 어느 등급인지 알고, 가격 차이를 보고, 내 업무에 맞는 모델과 요금제를 고를 수 있다.

## 핵심 한 줄

**이름보다 등급을 본다. 같은 회사 안에서도 값이 100배 차이 난다.**

> 이 시간의 모델 이름과 가격은 **2026년 10월 16일** 각 회사 공식 페이지 기준이다. 몇 주 단위로 바뀌므로 결제 전에 다시 확인한다.

## 모든 회사가 세 칸을 둔다

모델 이름은 제각각이지만 구조는 비슷하다.

| 등급 | 특징 | 언제 쓰나 |
| --- | --- | --- |
| 최상위 | 가장 똑똑하다. 비싸고 느리다 | 어려운 분석, 오래 걸리는 작업 |
| 기본 | 성능과 속도의 균형 | 대부분의 업무 |
| 가벼운 모델 | 빠르고 싸다 | 많은 양의 단순 작업(분류, 추출, 짧은 답) |

새 모델 이름이 나오면 이 세 칸 중 어디인지만 확인한다.

## API 가격 읽는 법

**API 가격**은 개발자가 자기 프로그램에서 모델을 부를 때 쓴 양만큼 내는 가격이다. 단위는 100만 **토큰**당 달러다. 토큰은 글을 잘게 자른 조각이다. 입력은 내가 보낸 글, 출력은 AI가 만든 글이다.

수강생이 직접 낼 일은 드물다. 그래도 모델끼리 얼마나 비싼지 비교하기에는 이 숫자가 정확하다.

| 비교 | 출력 가격 |
| --- | --- |
| GPT-6 Astra : GPT-6 Luna | $50 : $0.50 → 100배 |
| Claude Fable 5.1 : Claude Haiku 5.5 | $50 : $0.50 → 100배 |
| Claude Opus 5.5 : Claude Sonnet 5.5 | $20 : $10 → 2배 |

## 수강생이 실제로 내는 돈: 요금제

앱을 쓰는 사람은 월 구독료를 낸다. 미국 요금 기준이다. 사는 주에 따라 판매세(sales tax)가 더해질 수 있다.

| 회사 | 무료 | 개인 유료 | 고급 | 팀·회사 |
| --- | --- | --- | --- | --- |
| Claude | 무료 (Claude Code 없음) | Pro $20 | Max $100부터 | Team 1인 $25부터 |
| ChatGPT | 무료 | Go $8, Plus $20 | Pro $100·$200·$500 | Business 1인 $25부터 |
| Google AI | 무료 | Plus $4.99, Pro $19.99 | Ultra $99.99부터 | Workspace 요금제 별도 |

- 연 단위로 결제하면 대부분 조금 싸다.
- 요금제가 높을수록 쓸 수 있는 양이 늘고, 최상위 모델과 새 기능(dots, Gemini Spark 등)을 먼저 쓴다.

## 나는 이렇게 고른다

여기서부터는 내 해석이다.

| 상황 | 고르는 것 |
| --- | --- |
| 처음 시작한다 | 무료 요금제, 앱이 기본으로 골라 주는 모델 |
| 한두 주 써 보니 사용량 제한에 자주 걸린다 | 개인 유료 요금제(월 20달러 안팎) |
| 기본 모델의 결과가 부족하다 | 그 일만 최상위 모델로 다시 해 본다 |
| 같은 일을 수백 건 처리해야 한다 | 가벼운 모델. 다만 이건 대개 개발자와 함께 한다 |
| 회사 자료를 다룬다 | 모델보다 먼저 회사용 요금제인지 확인한다([3-1. 보안](03-보안-1.md)) |

비싼 모델이 요청을 대신 써 주지는 않는다. 요청이 막연하면 최상위 모델도 막연한 결과를 낸다. 모델을 바꾸기 전에 [2. 프롬프트](02-프롬프트.md)의 네 칸부터 확인한다.

> ✍️ **[채우기]** 같은 요청을 기본 모델과 최상위 모델, 또는 다른 회사 모델에 넣어 본 실제 비교. 결과가 얼마나 달랐고, 그 차이가 값 차이만큼이었는지 말한다.

## 정리

- 모델은 최상위·기본·가벼운 모델의 세 칸이다. 이름보다 칸을 본다.
- 같은 회사 안에서도 최상위와 가벼운 모델은 100배 차이가 난다.
- 수강생이 내는 돈은 대개 월 20달러 안팎의 개인 요금제다. 고급 요금제는 필요가 확인된 뒤에.
