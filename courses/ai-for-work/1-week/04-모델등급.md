# 4. 모델 등급과 고르는 법

> [목차](index.md) · 이전: [3. AI 도구 용어 한눈에](03-도구용어.md) · 다음: [5. 프롬프트 엔지니어링](05-프롬프트.md)

## 이 시간의 목표

새 모델 이름을 듣고 그 회사의 어느 등급인지 알아보고, 내 일과 내 요금제에 맞는 모델을 고를 수 있다.

## 핵심 한 줄

**좋은 모델보다 맞는 모델. 이름보다 등급을 본다.**

> 모델 이름과 가격은 **2026년 10월 26일** 기준이다. AI 가격은 자주 바뀌므로 강의 직전에 각 회사의 공식 가격 페이지에서 다시 확인한다.

## 먼저: 우리는 토큰값이 아니라 구독료를 낸다

이 시간에 나오는 달러 가격은 대부분 **API 가격**이다. API 가격은 개발자가 자기 프로그램에서 모델을 부를 때, 쓴 양만큼 내는 값이다.

ChatGPT, Claude, Gemini 앱을 쓰는 우리는 이 값을 내지 않는다. **월 구독료**를 낸다. 같은 구독료 안에서 쓸 수 있는 모델과 사용량이 정해져 있다.

| 회사 | 무료 | 개인 유료 | 고급 | 팀·회사 |
| --- | --- | --- | --- | --- |
| Claude | 무료 (Claude Code 없음) | Pro $20 | Max $100부터 | Team 1인 $20부터 |
| ChatGPT | 무료 | Go $8, Plus $20 | Pro $100·$200·$500 | Business 1인 $20부터 |
| Google AI | 무료 | Plus $4.99, Pro $19.99 | Ultra $99.99부터 | Workspace 요금제 별도 |

요금제 표는 2026년 10월 26일 기준이다. 팀·회사 요금제는 2명부터이고, 1인 $20은 1년 단위로 결제할 때 값이다. 달마다 결제하면 1인 $25다. 사는 주에 따라 판매세(sales tax)가 더해질 수 있다. 자세한 내용은 [참고: 회사별 최신 모델](참고/최신모델.md)에 있다.

그래서 아래 가격표는 **내가 낼 돈이 아니다.** 같은 회사 안에서 등급끼리 얼마나 차이가 나는지 보여 주는 자로만 쓴다. 여기서부터는 내 해석이다. 최상위 모델이 비싼 요금제에만 열리거나 같은 요금제에서도 사용량 제한에 더 빨리 걸리는 것은, 회사가 치르는 값이 이만큼 차이 나기 때문이라고 본다.

## 등급은 어떻게 나뉘나

**등급(tier)**은 한 회사가 같은 세대의 모델을 성능, 속도, 가격에 따라 여러 개로 나눠 내놓은 것이다. Claude의 Haiku, Sonnet, Opus가 대표적이다.

[1](01-LLM구조.md)에서 본 **파라미터** 수도 성능에 영향을 준다. 하지만 회사들이 내세우는 차이는 그보다 **어디에 맞춰 다듬었나**다.

- **학습한 자료의 질**: 무엇을, 얼마나 좋은 자료로 배웠나
- **추론 능력**: 얼마나 깊이 따지도록 다듬었나
- **도구 사용**: 검색, 코드 실행 같은 도구를 얼마나 잘 쓰도록 만들었나

나는 이것을 **같은 뼈대에 다른 근육을 붙인 것**에 빗댄다.

| 등급 | 근육 | 지향점 |
| --- | --- | --- |
| 가벼운 모델 (Haiku) | 최소한 | 속도 |
| 기본 (Sonnet) | 균형 | 균형 |
| 최상위 (Opus) | 최대한 | 정확도 |

모델의 내부 사양은 대부분 회사가 밝히지 않는다. 우리가 확인할 수 있는 것은 겉으로 드러난 성능 차이, 가격, 속도다.

## 같은 모델, 다른 생각 시간

**추론 깊이(effort)**는 모델을 쓰는 그 순간에 답하기 전 얼마나 오래 생각할지 정하는 설정이다. 모델을 바꾸는 것이 아니다. 같은 모델이라도 이 설정만 바꾸면 결과가 달라진다.

| 설정 | 생각 시간 | 품질 | 비용 | 응답 속도 |
| --- | --- | --- | --- | --- |
| 낮음 | 짧게 | 간단한 문제에 충분 | 싸다 | 빠르다 |
| 높음 | 오래 | 복잡한 문제에 강하다 | 비싸다 | 느리다 |

[2](02-LLM발전.md)의 비유로 보면 낮은 설정은 시스템 1, 높은 설정은 시스템 2에 가깝다. 앱마다 이 설정의 이름과 위치가 다르다. 강의에서 내 화면으로 보여 준다.

## 회사별 등급과 가격

- **토큰(token)**: AI가 글을 읽고 쓰는 단위다. 글을 잘게 자른 조각이다. 한국어는 대략 글자 한두 개, 영어는 낱말 하나나 그 일부다.
- **입력·출력 가격**: AI에게 보내는 글(입력)과 AI가 쓰는 글(출력)에 따로 값을 매긴다. 아래 가격은 모두 **토큰 100만 개당 달러**다.
- **컨텍스트(context)**: AI가 한 번에 읽고 기억할 수 있는 글의 양이다. 1M은 토큰 100만 개다.

### Anthropic (Claude)

| 모델 | 입력 / 출력 | 용도 |
| --- | --- | --- |
| Claude Fable 5.1 | $10 / $50 | 오래 걸리는 에이전트 작업. 가장 느리다 |
| Claude Opus 5.5 | $4 / $20 | 오래 걸리는 작업, 지식 업무 |
| Claude Sonnet 5.5 | $2 / $10 | 속도와 성능의 균형. 일상 업무, 요약 |
| Claude Haiku 5.5 | $0.10 / $0.50 | 분류, 추출, 요청 나눠 보내기 같은 대량 작업 |

- Haiku 5.5는 한 번에 넣는 글이 10만 토큰을 넘으면 $0.50 / $2.50으로 오른다.

### OpenAI (ChatGPT)

| 모델 | 입력 / 출력 | 용도 |
| --- | --- | --- |
| GPT-6 Astra | $10 / $50 | 최상위. 가장 어려운 일을 처음부터 끝까지 |
| GPT-6.1 Sol | $2 / $10 | 기본. 균형 잡힌 고급 작업 |
| GPT-6 Luna | $0.10 / $0.50 | 대량 분류, 추출 |

- GPT-5.5 Pro($30 / $180)는 아주 어려운 경우를 위한 특수 모델이다. 이전 세대 GPT-5.6 Sol은 할인가 $4 / $20이 이어지고 있다.

### xAI (Grok)

| 모델 | 입력 / 출력 | 용도 |
| --- | --- | --- |
| Grok 4.7 | $2 / $6 | 항상 추론하는 최상위 모델 |
| Grok 4.6 | $2 / $6 | 최상위 |
| Grok 4.5 | $2 / $6 | - |
| Grok 4.20 / 4.3 | $1.25 / $2.50 | 중간 가성비, 1M 컨텍스트 |
| Grok Build 0.1 | $1 / $2 | 예산형 대량 작업 |
| Grok 4.1 Fast | $0.20 / $0.50 | 가장 빠르다 |

- Grok 4.7·4.6·4.5·4.20·4.3은 한 번에 넣는 글이 20만 토큰 이상이면 장문 가격이 붙는다. 예를 들어 Grok 4.7은 $4 / $12가 된다.

### Google (Gemini)

| 모델 | 입력 / 출력 | 용도 |
| --- | --- | --- |
| Gemini 4 Argon | $2 / $10 (2026년 11월 30일까지 도입가, 이후 $4 / $20) | 최상위 추론 |
| Gemini 3.8 Flash | $0.75 / $3.75 (2026년 12월 31일까지 도입가, 이후 $1.50 / $7.50) | 범용 |
| Gemini 3.5 Flash Lite | $0.30 / $2.50 | 대량 작업용 최저가 |

## 가격의 공통 구조

Anthropic과 OpenAI는 거의 같은 사다리를 쓴다.

| 등급 | 입력 / 출력 (100만 토큰당) |
| --- | --- |
| 최상위 | 약 $10 / $50 |
| 기본 | 약 $2 / $10 |
| 가벼운 모델 | 약 $0.10 / $0.50 |

- 최상위와 가벼운 모델은 입력·출력 모두 **약 100배** 차이가 난다. GPT-5.5 Pro($30)까지 넣으면 입력 기준 약 300배다.
- 모든 회사가 이 사다리를 따르지는 않는다. xAI는 최상위가 $2 / $6으로 훨씬 납작하다. Google은 최상위도 도입가 기준 $2 / $10이다.

모든 일에 최상위 모델을 쓸 필요는 없다. 단순 분류에 최상위 모델을 쓰면 토큰 하나에 100배 값을 내는 셈이다. 실제로 드는 돈은 AI가 얼마나 길게 쓰고 오래 생각하느냐에 따라 달라진다. 구독료를 내는 우리에게는 돈 대신 **사용량 제한**으로 돌아온다. 최상위 모델은 같은 요금제에서도 금방 한도에 닿는다.

## 언제 무엇을 쓰나: Claude와 ChatGPT

### Claude

| 모델 | 이럴 때 | 예 |
| --- | --- | --- |
| Fable | 며칠 걸리는 큰 작업 | 투자 유치용 사업계획서, 수백 쪽 법률 문서의 위험 분석 |
| Opus | 얽히고설킨 큰 작업 | 여러 파일이 얽힌 자료를 통째로 읽고 구조를 파악한 뒤 일관되게 고치기 |
| Sonnet | 일상 업무 | 회의록 정리, 이메일 초안, 보고서 요약 |
| Haiku | 사람이 직접 쓰기보다 뒤에서 자동으로 | 고객 문의를 부서별로 나누기, 많은 글에서 정보 뽑기 |

Anthropic은 Claude를 처음 쓰는 사람에게 Opus 5.5에서 시작하라고 안내한다. 무료 요금제에서 어떤 모델을 쓸 수 있는지는 회사가 정하고 자주 바뀐다. 내 앱의 모델 선택 메뉴에서 확인한다.

### ChatGPT

| 모델 | 이럴 때 | 예 |
| --- | --- | --- |
| Astra | 한 주제를 처음부터 끝까지 맡길 때 | 시장 조사 → 경쟁사 분석 → 발표자료 초안까지 이어서 |
| Sol | 깊이 있는 분석과 작성 | 긴 문서 분석, 중요한 결정을 위한 참고 보고서 |
| Luna | 요청이 아주 많이 몰리는 곳 | 챗봇 서비스, 분류 작업 |

ChatGPT 앱의 일반 대화에서는 생각 수준에 따라 GPT-6 Sol이 답하고, 가장 깊은 Pro는 Astra를 바탕으로 한다. GPT-6.1 Sol 같은 별도 모델을 어디서 쓸 수 있는지는 내 요금제와 앱에서 확인한다.

## 나는 이렇게 고른다

여기서부터는 내 해석이다.

| 상황 | 고르는 것 |
| --- | --- |
| 처음 시작한다 | 무료 요금제, 앱이 기본으로 골라 주는 모델 |
| 한두 주 써 보니 사용량 제한에 자주 걸린다 | 개인 유료 요금제(월 20달러 안팎) |
| 기본 모델의 결과가 부족하다 | 그 일만 최상위 모델이나 높은 추론 깊이로 다시 해 본다 |
| 같은 일을 수백 건 처리해야 한다 | 가벼운 모델. 다만 이건 대개 개발자와 함께 한다 |
| 회사 자료를 다룬다 | 모델보다 먼저 회사용 요금제인지 확인한다. 이유는 [7](07-보안-2.md)에서 본다 |

비싼 모델이 요청을 대신 써 주지는 않는다. 요청이 막연하면 최상위 모델도 막연한 결과를 낸다. 모델을 바꾸기 전에 요청부터 고친다. 요청을 쓰는 법은 다음 시간 [5. 프롬프트 엔지니어링](05-프롬프트.md)에서 본다.

> ✍️ **[채우기]** 같은 요청을 기본 모델과 최상위 모델, 또는 다른 회사 모델에 넣어 본 실제 비교. 결과가 얼마나 달랐고, 그 차이가 값 차이만큼이었는지 말한다.

## 내 생각: 두 회사가 가는 방향

> **이 절은 사실 정리가 아니라 내 생각이다.** 회사가 공개한 방향과 내가 써 보며 느낀 경향을 묶은 것이다. 공식 발표를 옮긴 것이 아니고, 성능 비교 결과도 아니다.

여기서부터는 내 해석이다. 나는 두 회사가 이렇게 다른 쪽을 향해 왔다고 본다.

**Anthropic: 믿고 맡길 수 있는 행동**

- OpenAI 출신 연구자들이 나와 세운 회사다.
- 안전과 **해석 가능성(interpretability)**을 내세운다. 해석 가능성은 AI 안에서 무슨 일이 일어나는지 사람이 들여다보고 이해하려는 연구다.
- 나는 Claude가 도구를 부르고 그 결과를 이어받는 일을 안정적으로 한다고 느낀다. [2](02-LLM발전.md)의 ReAct, 즉 행동 쪽 줄기와 잘 맞는다고 본다.

**OpenAI: 더 깊은 생각**

- 모델 크기, 자료, 계산량을 키우면 성능이 좋아진다는 **스케일링 법칙(scaling law)**을 앞세워 온 회사다.
- 여기에 추론 모델을 얹었다. 답하기 전 생각 과정을 길게 늘려 답을 찾는다.
- 나는 ChatGPT를 쓸 때 "안에서 오래 생각한다"는 느낌을 받는다. 시스템 2, 즉 사고 쪽 줄기와 잘 맞는다고 본다.

| | Claude 계열 | OpenAI 계열 |
| --- | --- | --- |
| 내가 느끼는 강점 | 도구를 쓰고 결과를 이어받는 일이 예측 가능하다 | 추론 깊이를 바꿔 빠른 답과 깊은 답을 오간다 |
| 한마디로 | 행동의 신뢰성 | 사고의 깊이 |

**이 생각의 한계도 말해 둔다.** 두 회사 모두 긴 자료를 받는다(둘 다 컨텍스트 약 100만 토큰). 두 회사 모두 추론 깊이를 바꿀 수 있다. 그러니 이 차이는 성능표에서 나온 것이 아니라 내 체감이다. 모델이 바뀔 때마다 달라질 수 있다.

그래서 나는 회사보다 **일의 성격**으로 고르라고 권한다.

- 자료가 많고 길다 → 넓게 읽고 연결하는 일. 나는 Claude 쪽을 먼저 써 본다
- 문제가 어렵고 복잡하다 → 오래 생각하는 일. 나는 ChatGPT의 깊은 추론을 먼저 써 본다
- 단순하고 되풀이된다 → 어느 회사든 가벼운 모델

## 정리

- 우리는 토큰값이 아니라 구독료를 낸다. 가격표는 등급 사이의 차이를 보는 자다.
- 등급은 크기 경쟁이 아니라 용도별로 다듬은 결과다.
- 같은 모델도 추론 깊이를 바꾸면 품질, 속도, 비용이 달라진다.
- 같은 회사 안에서 최상위와 가벼운 모델은 토큰값이 약 100배 차이 난다. xAI와 Google은 더 납작하다.
- 좋은 모델보다 맞는 모델. 모델을 바꾸기 전에 요청부터 고친다.
- "Claude는 넓게 읽고 ChatGPT는 오래 생각한다"는 내 생각이다. 사실이 아니라 체감이다.
