- 확인 기준일: 2026년 10월 26일
- 검증 방법: 슬라이드 111장의 텍스트를 읽고, 주요 통계·가격·보관 기간·법정 기한을 웹 검색과 공식 원문으로 대조했다.

## 검토 결과

나는 핵심 보안 통계가 대체로 원문과 일치함을 확인했다. 다만 조사 대상이 빠진 통계, 개인정보 보관 기간, 가격 적용 조건은 수정이 필요하다. 현재 가격과 다른 항목은 과거 기준일의 오류로 단정하지 않고 최신 정보 반영 대상으로 구분했다.

### 권장 문구

68쪽의 49% 설명:

> 정보 탈취 악성코드에 감염된 사용자 데이터를 보니, 서로 다른 비밀번호의 비율은 중앙값 49%였다.

69쪽의 연구 범위 각주:

> Microsoft, 2023년 Azure AD 상용 계정 연구.

여기서부터는 내 해석이다. 이 통계는 비밀번호 재사용을 줄이고 MFA를 켜야 한다는 설명을 뒷받침한다. 하지만 ‘기술보다 사람이 먼저 뚫린다’는 문장 전체를 통계가 직접 증명하는 것은 아니다. 계정 정보 악용과 취약점 악용이 모두 주요 침입 경로라는 점을 함께 설명하는 편이 정확하다.

## 2. 우선 수정할 내용

### 79·81쪽 — Claude의 ‘학습을 끄면 30일 보관’

현재 공식 정책은 **대화를 삭제하면 서버에서도 30일 안에 삭제**한다고 설명한다. 학습 허용 시에는 학습 파이프라인에 비식별화된 데이터를 최대 5년 보관할 수 있다. 학습 설정만 끄면 저장된 대화가 30일 뒤 자동 삭제된다고 읽히는 문구는 고쳐야 한다.

권장 문구:

> 학습 사용 여부는 설정에서 고른다. 삭제한 대화는 서버에서 30일 안에 삭제된다. 학습을 허용하면 학습용 데이터가 최대 5년 보관될 수 있다.

출처: [Anthropic — How long do you store my data?](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data)

### 37쪽 — Team·Business의 시작 가격

현재 Claude Team 표준 좌석은 연간 결제 시 월 환산 $20, 월 결제 시 $25다. ChatGPT Business도 연간 결제 시 $20, 월 결제 시 $25이며 최소 2명 조건이 있다. Claude Team 역시 2명부터인 요금제다.

‘1인 $25부터’는 현재 최저가를 정확히 나타내지 못한다. 다만 슬라이드에 적힌 **10월 16일 당시 가격까지 확인한 것은 아니다.** 과거 오류로 단정하지 않고 최신 정보 반영 대상으로 본다.

권장 문구:

> Claude Team·ChatGPT Business: 1인당 월 $20부터. 연간 결제 기준, 최소 2명. 월 결제는 1인당 $25.

출처: [Claude 가격표](https://claude.com/pricing), [ChatGPT 가격 안내](https://learn.chatgpt.com/docs/pricing)

### 41쪽 — Haiku 5.5 가격 조건 누락

입력·출력 `$0.10 / $0.50`은 입력 길이 10만 토큰 이하일 때 맞다. 10만 토큰을 넘는 요청은 `$0.50 / $2.50`이다. 모두 100만 토큰당 달러다.

권장 각주:

> Haiku 5.5는 입력 10만 토큰 이하 기준. 초과 요청은 입력 $0.50 / 출력 $2.50.

출처: [Anthropic API 가격표](https://platform.claude.com/docs/en/about-claude/pricing)

### 42쪽 — Grok 가격 조건 누락

표에 적힌 Grok 4.7·4.6·4.5·4.3·4.20·Build의 기본 가격은 맞는다. 다만 입력이 20만 토큰 이상이면 장문 가격이 적용된다. 예를 들어 Grok 4.7은 입력·출력 `$2 / $6`에서 `$4 / $12`로 오른다. 모두 100만 토큰당 달러다.

권장 각주:

> Grok 가격은 입력 20만 토큰 미만 기준. 20만 토큰 이상은 장문 가격 적용.

출처: [xAI API 가격표](https://docs.x.ai/developers/pricing)

### 43·52쪽 — ‘같은 일에 100배’는 과한 해석

제시한 최고·최저 가격 사이에 토큰당 단가 100배 차이가 있다는 계산은 맞다. 하지만 실제 작업비는 생성량·추론량·도구 사용량에 따라 달라진다. 구독 사용량에도 API 단가가 그대로 적용된다고 일반화할 수 없다.

여기서부터는 내 해석이다. 단가 차이를 설명하는 자료로는 쓸 수 있지만, 동일한 업무의 총비용 차이를 확정하는 문장으로 쓰기에는 근거가 부족하다.

권장 문구:

> 같은 회사 안에서도 토큰당 단가는 약 100배 차이 날 수 있다. 실제 작업비와 구독 사용량은 처리 방식에 따라 달라진다.

출처: [OpenAI API 가격표](https://developers.openai.com/api/docs/pricing), [구독 사용량 안내](https://learn.chatgpt.com/docs/pricing)

### 45쪽 — ‘일반 대화에서 Sol을 고를 수 없다’는 최신화 필요

현재 공식 안내에서는 ChatGPT의 GPT-6 일반 대화에서 Instant·Medium·High·Extra High를 GPT-6 Sol이 처리한다고 설명한다. GPT-6.1 Sol과 GPT-6 Sol도 구분해야 한다. ‘Sol은 Work와 Codex에서만 쓴다’는 일괄 설명은 현재 안내와 맞지 않는다.

권장 문구:

> ChatGPT의 GPT-6 일반 대화에서는 생각 수준에 따라 GPT-6 Sol이나 Astra 기반 Pro를 쓴다. GPT-6.1 Sol 등 별도 모델의 사용 범위는 내 요금제와 앱에서 확인한다.

출처: [OpenAI — GPT-6 and other models in ChatGPT](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt)

## 4. 법정 기한과 순위 표현 보완

### 85쪽 — 텍사스 유출 통지 기한

60일·30일·250명이라는 숫자는 맞다. 다만 법은 부당한 지체 없이 통지하도록 요구하고, 60일·30일은 상한이다. ‘60일 안이면 기다려도 된다’는 인상을 피해야 한다. 법에는 수사기관 요청 등 예외도 있다.

권장 문구:

> 고객에게 지체 없이, 원칙적으로 유출 발생을 확인한 날부터 늦어도 60일 이내에 알린다. 텍사스 주민 250명 이상이면 주 법무장관에게도 가능한 한 신속히, 늦어도 30일 이내에 신고한다.

출처: [텍사스 Business & Commerce Code §521.053](https://tcss.legis.texas.gov/resources/BC/htm/BC.521.htm), [텍사스 법무장관 신고 안내](https://www.texasattorneygeneral.gov/consumer-protection/data-breach-reporting)

### 99쪽 — OWASP ‘1위’

프롬프트 인젝션이 2025년 목록의 LLM01 항목인 것은 맞다. 사고 발생 빈도를 측정한 통계 순위처럼 들리지 않도록 표현을 보완한다.

권장 문구:

> OWASP 2025 LLM 보안 위험 목록의 첫 번째 항목.

출처: [OWASP — LLM01:2025 Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)

## 5. 확인하지 못했거나 이번 검증에 포함하지 않은 범위

- Google 개인 구독의 Plus $4.99·Pro $19.99는 공식 페이지에서 가격을 충분히 재확인하지 못했다. 확인 완료로 처리하지 않는다.
- Grok 4.1 Fast의 현재 가격과 ‘가장 빠르다’는 표현은 공식 자료에서 충분히 재확인하지 못했다.
- 제품별 출시일·지역 제한 전체를 검증한 것은 아니다.
- 37쪽의 과거 기준일인 2026년 10월 16일 당시 가격을 별도로 복원하지 않았다.
- 모든 개념 설명과 법률 관련 문장을 전수 검증한 것은 아니다. 이 문서의 ‘확인’은 위에 명시한 항목에 한정한다.

## 6. 반영 우선순위

여기서부터는 내 해석이다. 나는 다음 순서로 반영한다.

1. **79·81쪽:** Claude의 학습 설정과 삭제 후 보관 기간을 구분한다.
2. **68쪽:** 비밀번호 49%에 조사 대상과 중앙값을 붙인다.
3. **37·41·42쪽:** 현재 구독 가격과 API 가격 적용 조건을 보완한다.
4. **43·52쪽:** 토큰당 단가와 실제 작업비를 구분한다.
5. **45쪽:** Sol의 일반 대화 사용 범위를 최신화한다.
6. **69·85·99쪽:** 연구 범위, 통지 기한의 성격, 목록 순위의 의미를 각주나 짧은 문장으로 보완한다.
