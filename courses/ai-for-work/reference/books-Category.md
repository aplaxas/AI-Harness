# AI 업무 활용 도서의 카테고리와 수준

나는 [교보문고 도서 소개·목차 모음](books-Kyobo.md)을 바탕으로 참고 자료를 아래처럼 분류한다. 여기서부터는 내 해석이다. 수준은 출판사가 정한 등급이 아니라 사무직 종사자와 소상공인을 기준으로 내가 정한 학습 난이도다. 책 본문과 제품의 실제 기능을 검증한 평가는 아니다.

카테고리와 수준을 정하고, 아래 도서 목록에 주 카테고리와 보조 카테고리를 배정한다. 강의 순서·시간은 이후에 정한다.

## 분류 기준

분류 깊이는 **대분류 → 카테고리**의 두 단계로 둔다. 대분류는 주제의 성격을 묶고, 카테고리는 책이나 장을 찾는 단위로 쓴다. 초급·중급·고급은 이 분류 깊이와 별개인 학습 수준이다.

업무 주제와 제품 이름은 구분한다. 예를 들어 엑셀 분석은 업무 활용이고, Cowork와 Codex는 그 일을 수행할 때 쓰는 도구다. 도구별 사용법을 찾을 수 있도록 별도 카테고리로 남긴다.

| 수준 | 기준 | 할 수 있어야 하는 일 |
| --- | --- | --- |
| 초급 | 안내와 예시를 따라 한 가지 작업을 수행한다. | 목적과 자료를 주고 초안을 받는다. 결과를 원문과 대조하고 수정 요청을 한다. |
| 중급 | 내 자료와 기준으로 여러 단계의 업무를 구성한다. | 파일·지침·도구를 조합하고, 결과물의 형식과 확인 기준을 정해 반복 사용한다. |
| 고급 | 반복 실행이나 팀 사용을 위한 운영 기준을 설계한다. | 권한·승인·오류 대응·비용·변경 기록을 관리하고, 실패하면 중단하거나 복구할 수 있게 한다. |

고급은 코딩 실력을 뜻하지 않는다. 업무를 맡기는 범위와 운영 책임이 넓어지는 수준을 뜻한다. 보안과 결과 검증은 모든 수준에 포함한다.

## 카테고리 표

‘기준 수준’은 해당 카테고리의 중심 내용을 배우는 수준이다. ‘수준별 범위’는 같은 주제 안에서 어디까지 다루느냐에 따른 구분이다. 번호는 분류 식별용이며 학습 순서가 아니다.

| ID | 대분류 | 카테고리 | 기준 수준 | 수준별 범위 |
| --- | --- | --- | --- | --- |
| C01 | 기본기 | AI 이해와 첫 사용 | 초급 | 초급: 생성형 AI의 한계, 도구 선택, 첫 대화, 기본 설정과 사용량 확인 |
| C02 | 기본기 | 질문·대화·프롬프트 설계 | 초급 | 초급: 목적·조건·출력 형식 전달, 수정 대화 / 중급: 문제 정의, 작업 분해, 재사용할 요청 틀 만들기 |
| C03 | 기본기 | AI 보안·개인정보·책임 있는 사용 | 초급 | 초급: 입력할 자료 구분, 민감정보와 저작권 주의 / 중급: 공유·연결 권한 점검 / 고급: 팀 정책과 사고 대응 기준 |
| C04 | 기본기 | 결과 검증과 품질 관리 | 초급 | 초급: 사실·출처·숫자 대조 / 중급: 업무별 검수표와 오류 사례 관리 / 고급: 반복 업무의 품질 평가와 변경 전후 비교 |
| C05 | 업무 활용 | 문서·이메일·회의 업무 | 초급 | 초급: 요약·초안·회의록 / 중급: 여러 문서를 합쳐 보고서 작성, 회사 양식과 문체 적용 |
| C06 | 업무 활용 | 자료 조사·지식·파일 관리 | 중급 | 초급: 자료 요약과 파일명 정리 / 중급: 여러 출처 비교, 원문 추적, 승인본·버전 관리, NotebookLM 같은 자료 기반 도구 활용 |
| C07 | 업무 활용 | 엑셀·데이터 분석 | 중급 | 초급: 수식 설명과 간단한 표 정리 / 중급: 누락·중복 확인, 집계·검산·차트·보고서 / 고급: 새 데이터에도 적용되는 분석 흐름 운영 |
| C08 | 업무 활용 | 발표·디자인·홍보 콘텐츠 | 중급 | 초급: 슬라이드 개요와 홍보 문구·이미지 초안 / 중급: PPT·카드뉴스·안내문 완성, 브랜드 기준과 채널별 형식 적용 |
| C09 | 작업 환경·도구 | AI 사용환경과 맥락 관리 | 중급 | 초급: 개인 맞춤 설정 / 중급: 프로젝트·작업 폴더·참고 자료·공통 지침 정리. 맥락은 AI가 작업에 참고할 배경과 자료를 뜻한다. |
| C10 | 작업 환경·도구 | Cowork 사용 | 중급 | 초급: 안내에 따라 샘플 파일 작업 / 중급: 작업 폴더와 권한을 정하고 문서 묶음 처리, 변경 결과 확인 |
| C11 | 작업 환경·도구 | Codex·Claude Code 업무 활용 | 중급 | 초급: 화면에서 예제 작업 따라 하기 / 중급: 작업 범위·지침·완료 기준을 주고 파일 결과물 확인. 코드·터미널 경험은 전제하지 않는다. |
| C12 | 확장·자동화 | 에이전트 이해와 업무 위임 | 중급 | 초급: 도구를 사용해 작업을 수행하는 AI라는 개념 이해 / 중급: 목표·작업 범위·사람의 확인 지점 설정 / 고급: 여러 에이전트의 역할 분담과 결과 통합 |
| C13 | 확장·자동화 | 스킬 활용과 제작 | 중급 | 초급: 준비된 스킬 사용 / 중급: 반복 업무의 절차·기준·출력 형식을 재사용할 설명서로 만들기 / 고급: 여러 스킬의 품질·변경·공유 관리 |
| C14 | 확장·자동화 | 플러그인·커넥터·외부 도구 연결 | 중급 | 초급: 개념과 연결 권한 이해 / 중급: 준비된 확장 묶음인 플러그인 사용, 외부 서비스 연결 수단인 커넥터 활용 / 고급: 맞춤 구성 제작과 팀 배포·권한 관리 |
| C15 | 확장·자동화 | 반복 업무 자동화와 운영 | 고급 | 중급: 정해진 업무 흐름과 예약 실행 구성 / 고급: 실패·중복 실행·중단·복구·실행 기록 관리 |
| C16 | 확장·자동화 | 작은 업무 도구 제작 | 중급 | 중급: 자연어로 요구를 설명해 명단 정리 도구·대시보드 등을 만들고 샘플로 확인 / 고급: 공유 후 수정·접근 권한·유지 관리 |
| C17 | 업무 전환·팀 운영 | AX와 팀 도입 | 중급 | 초급: AI로 일하는 방식을 바꾼다는 개념 이해 / 중급: 적용할 업무 선정과 효과 확인 / 고급: 팀 역할·승인·교육·비용·인수인계 설계 |

## 초안에서 조정한 부분

| 기존 항목 | 정리한 기준 |
| --- | --- |
| Prompt Engineering: 초보 | C02로 유지한다. 표기는 ‘초급’으로 통일하고, 질문·대화부터 반복 사용할 요청 설계까지 구분한다. |
| AI 보안: 초보 | C03의 기준은 초급이다. 팀 정책과 사고 대응까지 다루면 고급이다. 결과의 정확성 확인은 C04로 따로 둔다. |
| AX(AI 사용환경): 중급 | 개인의 AI 사용환경은 C09, AI를 활용해 업무 방식과 조직 운영을 바꾸는 AX(AI Transformation)는 C17로 나눈다. 원자료의 4·21번 도서도 개인 설정을 넘어 업무·조직 전환을 다룬다. |
| 엑셀 with AI: 중급 | C07로 유지한다. 사무직·소상공인은 난이도가 아니라 대상 태그로 분리한다. |
| Cowork / codex: 중급 | C10·C11로 유지한다. Codex와 함께 원자료에 반복해서 나오는 Claude Code를 C11에 묶고, 제품명은 도구 태그로 구분한다. |
| agents: 초급·중급·고급 | C12에서 개념 이해·업무 위임·역할 분담으로 수준의 경계를 정한다. |
| skills: 중급 | C13으로 유지한다. 준비된 스킬 사용과 직접 제작·운영을 구분한다. |
| plugins: 고급 | C14의 기준은 중급으로 조정한다. 원자료 9번 도서처럼 준비된 플러그인 사용과 맞춤 제작·운영은 나누어 볼 필요가 있다. |

원자료에 반복해서 등장하지만 초안에 없던 첫 사용, 결과 검증, 문서·회의, 조사·파일 관리, 발표·홍보, 반복 자동화, 작은 도구 제작을 추가했다. 이 표는 참고 도서를 찾기 위한 분류다. 모든 카테고리를 강의에 넣는다는 뜻은 아니다.

## 도서 배정 규칙

나는 책 한 권에 주 카테고리 하나와 보조 카테고리를 붙인다. 여러 주제를 넓게 다루는 책은 필요한 장별로도 분류한다. 어려운 부록 하나 때문에 책 전체를 고급으로 올리지 않고, 중심 내용의 수준과 심화 범위를 따로 적는다.

대상은 `사무직`, `소상공인·1인 사업자`, `팀장·관리자`처럼 별도 태그로 남긴다. 도구도 `ChatGPT`, `Cowork`, `Codex`, `Claude Code`, `NotebookLM`, `엑셀`처럼 별도 태그로 남긴다. 예를 들어 ‘엑셀 분석’과 ‘Codex로 엑셀 분석하기’를 주제와 도구 양쪽에서 찾을 수 있게 한다.
