# 강의계획서 — AI와 일하는 법

> 3주 과정 · 주 1회 · 회당 3시간 · 총 9시간

## 과정 소개

Chatbot(Claude/ChatGPT)에게 질문을 해 본 경험이 있는 사람이 agent에게 실제 업무를 맡기는 단계까지 가는 과정이다.

- 1주차에는 AI 도구를 고르고, 요청을 쓰고, 자료를 지키는 기본을 익힌다.
- 2주차와 3주차에는 어떤 에이전트를 쓰든 똑같이 적용되는 업무 위임 가이드를 먼저 세우고, 업무 하나를 OpenAI의 Codex-Work와 Anthropic의 Claude Cowork에 각각 적용해 본다. 개별 Agent 사용법을 따로 외우는 대신, 하나의 설계가 agent마다 어디에 어떻게 적용되는 알아 본다.
- 코드, 터미널, 개발 지식은 필요 없다.

## 대상

- AI를 써 봤지만 "질문하고 답 받기"에서 더 나아가지 못한 사람
- 문서·메일·회의·엑셀 업무가 많은 사무직 종사자
- 고객 응대·홍보·매출 정리를 혼자 하는 소상공인
- 생화학 연구 개발자

## 과정을 마치면

1. AI 도구 이름을 듣고 무엇을 하는 도구인지, 내가 쓸 수 있는지 말할 수 있다.
2. 목적·자료·조건·결과 형식을 갖춘 요청을 쓰고, 결과를 구체적으로 고쳐 달라고 할 수 있다.
3. AI에 넣으면 안 되는 자료를 구분하고, 설정과 권한을 직접 점검할 수 있다.
4. 채팅과 agent(작업위임)의 차이를 알고, 업무에 맞는 방식을 고를 수 있다.
5. 도구와 상관없이 쓸 수 있는 agent 가이드로 업무를 설계하고, 같은 업무를 Codex·ChatGPT Work와 Claude Cowork에 각각 적용 할수 있다.
6. 내 업무 하나를 골라 "자료 → 요청 → 확인 → 기록"의 흐름으로 정리할 수 있다.

## 준비물

| 준비물 | 1주차 | 2주차 | 3주차 |
| --- | --- | --- | --- |
| 노트북 | 필요 | 필요 | 필요 |
| ChatGPT 계정 | 무료 가능 | 필요 (데스크톱 앱 설치) | 필요 |
| Claude 계정 | 무료 가능 | 필요 (데스크톱 앱 설치) | 필요 |
| Gemini 계정 | 선택 | — | — |
| 실습용 자료 | 강사 제공 | 강사 제공 + 내 업무 자료 복사본 | 강사 제공 + 내 업무 자료 복사본 |

- 유료 계정 없으면 강사 화면 시청
- 2·3주차에 가져올 내 업무 자료는 반드시 복사본으로, 개인정보와 회사 기밀을 지운 상태로 가져온다. 기준은 1주차에 배운다.

## 주차별 계획

### 1주차 — AI와 일하는 기본기

**목표**

- AI 도구와 모델의 이름을 정리하고, 내가 쓰는 도구가 어디에 속하는지 안다.
- 목적·자료·조건·결과 형식을 갖춘 요청을 쓰고, 첫 결과를 구체적으로 고친다.
- AI에 넣으면 안 되는 자료를 구분하고, 내 계정의 학습 설정을 점검한다.
- 회사별 모델의 등급과 가격 차이를 보고 요금제를 고른다.

**과제**: 자주 하는 업무 세 가지를 적고 그중 하나를 실습거리로 고른다. 필요한 자료의 복사본을 만들고 개인정보와 기밀을 지운다.

### 2·3주차의 구조: 가이드 하나, 에이전트 둘

2·3주차에서는 모든 에이전트에 공통으로 적용할 수 있는 업무 위임 가이드를 먼저 정립한다. 이어서 동일한 업무를 Codex ChatGPT Work/Claude Cowork에 각각 적용하고, 가이드의 각 항목을 도구별로 어디에서 어떻게 실행하는지 비교해 보여 준다.

**업무 위임 가이드 (도구 공통)**

| 항목 | 정하는 것 |
| --- | --- |
| 1. 목표와 완료 기준 | 무엇이 되면 끝인가, 결과물은 무엇인가 |
| 2. 작업 폴더 | 원본·작업본·결과를 어떻게 나누나. 원본은 복사본으로 |
| 3. 권한과 승인 | 무엇을 읽고 쓰게 하나, 어떤 단계에서 내 승인을 받나 |
| 4. 위임 요청서 | 목적·자료·조건·결과 형식, 하지 말 것 |
| 5. 진행 확인 | 계획과 중간 결과를 어디서 보고 언제 멈추나 |
| 6. 결과 검수 | 무엇을 만들고 무엇을 고쳤나, 원문 대조와 검산 |
| 7. 기록과 재사용 | 잘된 요청과 고친 이유를 지침으로 남기기 |

**같은 가이드, 다른 적용**: 가이드의 각 항목을 도구별로 나란히 비교한다. 폴더 연결방식, 권한과 승일 설정 위치, 진행 상황 확인 방법등. 그러나 요청서의 내용과 검수 기준은 agent가 바뀌어도 동일하다는 원칙을 배운다.

### 2주차 — 가이드 세우기와 첫 적용

**목표**

- 채팅과 agent(작업위임)의 차이를 알고, agent에서 새로 생기는 위험을 안다.
- agent공통의 업무 위임 가이드 일곱 항목을 이해하고 내 업무에 채워 본다.
- 같은 업무(예: 회의 메모 여러 개 → 회의록 파일)를 Codex·ChatGPT Work와 Claude Cowork에 각각 맡겨 보고, 가이드의 각 항목이 두 도구에서 어떻게 다르게 구현되는지 비교한다.
- 두 결과를 같은 검수 기준으로 원문과 대조한다.

**과제**: 1주차에 고른 내 실습거리를 가이드 일곱 항목으로 설계하고, 두 도구 중 하나로 처리해 결과와 고친 점을 기록한다.

### 3주차 — 여러 단계의 업무와 내 업무 적용

**목표**

- 여러 단계가 이어지는 업무(예: 고객 문의·매출 엑셀 → 분류·요약 → 보고서·안내문)를 같은 가이드로 설계하고 두 도구에 적용한다.
- 진행 확인과 승인 지점이 두 도구에서 어떻게 다른지 비교한다.
- 잘된 요청을 각 도구의 지침으로 남겨, 다음에 같은 일을 다시 설명하지 않게 한다.
- 내 업무 하나를 가이드로 정리하고, 어느 도구가 왜 맞았는지 발표한다.

## 전 과정에 걸쳐 지키는 원칙

- AI가 만든 결과는 초안이다. 사실 확인, 약속, 결정, 발송은 사람이 한다.
- 원본은 건드리지 않는다. 작업 위임은 항상 복사본 폴더에서 한다.
- 필요한 만큼만 열어 준다. 폴더 하나, 읽기 권한부터 시작한다.
- 되돌릴 수 없는 일 앞에는 승인을 둔다. 발송, 삭제, 결제, 공개.
- 잘된 요청과 고친 이유를 기록한다. 다음에 처음부터 다시 쓰지 않기 위해서다.
