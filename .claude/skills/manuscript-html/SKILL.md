# 원고 → 책 디자인 HTML

원고 마크다운이 정본이다. HTML은 언제든 다시 만드는 산출물이다. 그래서 만들어진 HTML은 손으로 고치지 않는다. 다음 변환 때 덮어써지기 때문이다. 디자인을 바꾸려면 `assets/template.html`을 고친다. 변환 규칙을 바꾸려면 `scripts/build.mjs`를 고친다.

## 실행

Node 18 이상만 있으면 된다. 외부 패키지는 쓰지 않는다. macOS와 Windows에서 명령이 같고, 한글 경로는 따옴표로 감싼다.

```bash
# 절 하나 + 목차 페이지(index.html)
node .claude/skills/manuscript-html/scripts/build.mjs "courses/ai-for-work/manuscript/01-01-역할구분.md"

# 폴더의 모든 절 + 목차 페이지
node .claude/skills/manuscript-html/scripts/build.mjs --all courses/ai-for-work/manuscript
```

- 절 하나에서 HTML 두 개가 나온다. 책에서 장 시작 페이지와 본문이 나뉘는 것과 같다.
  - `01-01-Title.html`: 빨간 부 표지. `Part 01`, 부 제목과 부제, 그 장의 절 목록(현재 절은 ▸로 강조)
  - `01-01-역할구분.html`: 본문. `Chapter 01` 장 제목, 절 제목, 도입부, 핵심 키워드, 그리고 본문
- 읽는 순서는 목차 → 1.1 Title → 1.1 본문 → 1.2 Title → …이고, 이전·다음 카드가 이 순서로 이어진다. 목차 페이지의 절 링크는 Title 페이지로 간다.
- 키워드가 한글이면 파일 목록에서 Title이 본문보다 먼저 정렬된다. 영어 키워드가 A~S로 시작하면 본문이 먼저 올 수 있다.
- 출력 위치는 manuscript 폴더 옆의 `html/`이다(예: `courses/ai-for-work/html/`). 다른 곳에 두려면 `--out <폴더>`를 붙인다.
- 이미지는 HTML 안에 넣는다. 그래서 파일 하나만 보내거나 올려도 그림이 보인다.
- `index.md`가 있으면 목차 페이지를 매번 함께 다시 만든다. 이전·다음 링크와 목차 링크가 이 페이지로 이어지기 때문이다.
- 공유하거나 웹에 올리기 직전에는 `--all`로 전체를 다시 만든다. 절 하나만 만들면 다른 절의 이전·다음 링크가 옛 상태로 남는다.

## 원고에서 읽는 것

변환기는 원고 표기를 다음처럼 해석한다. 새 표기가 필요하면 `build.mjs`에 추가하고 이 표에도 적는다. 표에 없는 표기는 일반 마크다운으로 처리된다.

| 원고 표기 | HTML에서 |
| --- | --- |
| 파일명 `01-01-키워드.md` + `index.md`의 부·장·절 | Title 페이지의 부 표지와 절 목록, 본문 페이지의 `Chapter 01` 장 제목, 상단 경로(목차 › Part 01 › 1장) |
| `# 1.1 제목` | 절 번호와 제목 |
| 제목 바로 아래의 링크 인용 블록(`> [목차](index.md) · 다음: ...`) | 본문에서 빼고, 이전·다음 카드와 상단 경로로 바꿔 만든다. 이전·다음은 실제로 있는 파일 순서로 다시 계산한다 |
| 첫 `##` 앞의 문단 | 본문 페이지 제목 아래의 도입부 |
| 일반 문단의 `**굵은 말**` | "핵심 키워드" 목록. 목록·표·인용 속 굵은 글씨는 넣지 않는다 |
| `> ✍️ **[채우기]** ...` | 점선 "채우기" 상자. 툴바의 "집필 메모 숨김"으로 가릴 수 있다 |
| `> **NOTE**`, `> **TIP**`, `> **궁금해요**`, `> **주의**`, `> **참고**` | 라벨이 붙은 콜아웃 상자 |
| "여기서부터는 내 해석이다"로 시작하는 문단 | 왼쪽 선과 "내 해석" 표시 |
| 한 줄에 이미지만 있는 `![설명](images/...)` | 번호 붙은 그림(`그림 1.1-1 설명`). 누르면 크게 보인다 |
| 빈 행이 있는 표 | 독자가 칸에 직접 적는 워크시트. 적은 내용은 그 브라우저에만 저장된다 |
| `##`, `###` | 왼쪽 "이 절의 구성" 목차. 읽는 위치를 따라 표시된다 |

화면에는 읽기 진행 막대, 글자 크기 조절, 밝게·어둡게 전환, 인쇄 버튼이 있다. 인쇄할 때는 툴바와 목차를 숨긴다.

## 변환한 뒤 확인

1. 명령 출력의 `경고:` 줄을 본다. 없는 이미지나 지원하지 않는 형식이 여기에 나온다.
2. 화면을 확인한다. 브라우저로 열거나 헤드리스 Chrome으로 스크린샷을 찍어 본다.

   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
     --virtual-time-budget=4000 --window-size=1400,4000 --screenshot=/tmp/page.png \
     "file://$PWD/courses/ai-for-work/html/01-01-역할구분.html"
   ```

   헤드리스 Chrome은 창 폭이 500px보다 좁아지지 않는다. 휴대폰 폭을 보려면 375px 폭의 `<iframe>`에 페이지를 넣은 HTML을 따로 만들어 스크린샷을 찍는다.
3. 사용자에게 만든 파일 경로를 알려 준다.

## 지원하지 않는 것

참조식 링크(`[글][B27]`), 각주, 인용 블록 안의 중첩 인용은 해석하지 않는다. 원고에 필요해지면 변환기에 추가한다.
